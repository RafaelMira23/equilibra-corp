# Equilibra Corp.

Site institucional do projeto educacional da turma 17574 do Programa Jovem Aprendiz Espro.

**Bem-estar que transforma.** Saúde física e mental para ambientes de trabalho mais humanos.

## Publicação no GitHub Pages

1. Crie o repositório público `equilibra-corp` e envie estes arquivos para a branch `main`.
2. Em **Settings → Pages → Build and deployment**, escolha **Deploy from a branch**.
3. Selecione **main**, pasta **/ (root)** e clique em **Save**.
4. Aguarde a publicação e abra o endereço informado pelo GitHub Pages.

O site usa HTML, CSS e JavaScript, sem dependências ou etapa de compilação. O arquivo `.nojekyll` mantém os arquivos estáticos sem processamento do Jekyll. Os caminhos relativos dos recursos permitem a publicação em uma subpasta de projeto.

## Organização

- `index.html`: conteúdo e estrutura do site.
- `assets/styles.css`: identidade visual e layouts responsivos.
- `assets/app.js`: menu e abas acessíveis dos departamentos.
- `assets/`: imagens da apresentação fornecida pela equipe.

## Conteúdo e escopo

Esta versão preserva o one pager inicial, baseado na apresentação fornecida em 16 de outubro de 2026. A apresentação em desenvolvimento enviada em 23 de outubro foi recebida como contexto para futuras revisões; seu conteúdo ainda não foi incorporado ao site.

A pesquisa apresenta 47 respostas coletadas em maio de 2026. As fotografias são ilustrativas e constam na apresentação original. As atividades estão identificadas como propostas.

A Equilibra Corp. é uma empresa fictícia de caráter educacional e não realiza atendimento clínico. Esta versão não contém painel administrativo, cadastro de pessoas ou coleta de dados. Uma futura área administrativa exigirá autenticação e armazenamento em um serviço de servidor separado do GitHub Pages.
